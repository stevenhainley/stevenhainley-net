01 · Product

Glim

Glim is the second brain for your business. It connects the tools you already use, your people and the best AI models (local ones when it can) and keeps the work moving. I set it up on-site and run it with you. It doesn't replace your team; it gives them their time back.

  • Set up on the client's own Mac, so the data stays there
  • Moves between models: local for routine work, larger ones when the job needs it
  • Anything that spends money or goes public waits for a person to approve it
02 · Mac app

Glim for Mac

sh. desk is the native Mac app I run the company from, and the app Glim clients will use. It's a native Swift app.

  • The bar: talk or type to Glim from anywhere, with speech-to-text running locally
  • The pet: a tiny Glim that floats on the screen and shows what it's working on
  • A built-in browser with tabs, which Glim can drive only when I allow it
  • Touch ID lock, onboarding, settings and an off switch for everything
03 · sh. Studio

Clip engine

The system behind sh. Studio. It turns a podcast episode into finished shorts, and I review every clip before a client sees it.

  • Clips end on a finished thought, not just the end of a sentence
  • Active-speaker framing, and an editing style matched to the show from a database of how top podcasts cut their clips
  • Every clip gets a score with its top three reasons
  • Learning loop: each night it compares how shipped clips actually did with what it predicted, and retunes the scorer in small, logged steps
04 · Website

shindustries.co

I designed and built the company site with Glim: product pages, legal pages, a Simple mode and a 404 page where Glim lives. Every price on it comes from one config file, so the site can't drift from checkout.

05 · HARDWARE SECURITY · OCT 2026 → PRESENT

My BadUSB

I programmed a Raspberry Pi Pico W to act like a keyboard. Plugged into a computer (with the owner's permission), it types the commands that open my LinkedIn profile or résumé.

  • Separate Windows and macOS payloads, written in CircuitPython + Adafruit HID
  • A file-based lock keeps the payload off so I can edit the code safely
  • Seeing a computer trust a "keyboard" made device trust and physical access click

06 · EMBEDDED · IN PROGRESS

Paddy:
less phone, more golf

A pocket device built on a Pico W to keep the focus on the round. It's turning into a small app platform: apps get only the permissions they declare, and I test them in a simulator before they touch the hardware.

  • First apps: golf scorecard, GPS, Wi-Fi list, battery, clock and alerts
  • Permission manifest per app; anything undeclared raises an error
  • Safe mode and a watchdog so a bad app can't brick the device
